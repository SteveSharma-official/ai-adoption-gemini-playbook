# Getting Started

1. Install Python 3.11 or later.
2. From the repository root: `python -m pip install -r requirements.txt`
3. Start Lab 0.1: `python shared/scripts/start-lab.py 0.1`, then `cd workspace/lab-0.1` and `python run.py`.
4. Read `evidence/report.md`. Every lab produces the same evidence pack.
5. Work through the labs in book order, or jump to the chapter you are reading. Each lab README names its book section.
